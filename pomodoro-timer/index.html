Rules, limits & privacy

Enter work, short break and long break durations as whole minutes from 1 to 240; choose 1–12 work sessions per set. Each work session is followed by a short break except the last, which has a long break. The set ends after the long break. Deadlines use the device clock, so background throttling or device sleep may delay visual updates and sound. Sound is optional and requires a user gesture; browser policies may prevent audio. Keep this page open.

Hosting and the existing styling CDN are separate network requests. User input is not uploaded by this tool.
