# Printable Calendar Generator

Canonical route: `printable-calendar-generator/index.html`.

Years 1–9999; month and week start are explicit. Languages: English (UK/US), French and Spanish. Previous/next controls stop at year boundaries. Print uses the current generated calendar; no holidays are inferred.

Processing stays in the browser; hosting and the existing Tailwind styling CDN are separate network requests. Publication is pending separately authorized integration and live verification.
