# Task 11 — File Size Converter contract

The user authorized this planned tool and a feature PR; the milestone remains 24/25 until separate merge, deployment and live verification. The tool has distinct SI/IEC byte-unit conversion functionality and does not require a file parser, external API or new dependency. Existing Tailwind CDN hosting remains separate from local input processing.

Input is a nonnegative plain decimal string, no sign, exponent, separator, or whitespace inside; trim surrounding whitespace. Limit to 60 UTF-16 units and at most 30 fractional digits; reject larger inputs without truncation. BigInt rational arithmetic represents the entered decimal and powers of 1000 or 1024 exactly. Eleven unique units B, kB, MB, GB, TB, PB, KiB, MiB, GiB, TiB, PiB. Default B to kB. Round half up to at most 12 decimal places, strip trailing zeros, prefix rounded results with approximately; a nonzero result below 0.000000000001 is displayed as less than that threshold rather than an apparent exact zero. Zero is exact. No IEEE floating-point precision loss, exponent input, hidden file reading or data upload. Output includes destination unit and copy selects output if clipboard fails; clear restores defaults. Include existing download control for framework compatibility.

Tests: independent rational SI/IEC/cross conversions, same-unit/zero/decimals, tiny rounded values, boundary lengths/precision, invalid/negative/Unicode/large inputs and unsupported settings; browser copy/failure/reset, keyboard, responsive layouts, error/stale result and navigation; full regression and project validation. Source/test commit precedes dated source-bound TESTED evidence; publication remains null. CI coverage extends existing map without weakening tests.
