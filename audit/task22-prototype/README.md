# Pre-production Task 22 gate archive

These are scratch prototype snapshots, not runtime dependencies or pages. `security-gate.txt` records the 30-case successful run before production adoption. The browser control page and isolated Worker include a test-only raw-generated-HTML sanitation operation; the production Worker does not expose it. The two earlier harness corrections concerned expected trailing newlines and fixtures whose sanitizer removed every element; no execution/network/origin escape was observed.

To reproduce outside the repository, create sibling scratch directories `work/candidate` and `work/task22` (the latter a checkout of the recorded baseline). Copy this archive to `candidate`, copy `prototype-html.txt` to `prototype.html`, and extract the integrity-verified Marked 18.1.3 package under `candidate/packages/marked-18.1.3`. Bundle `candidate/worker.mjs` with the pinned esbuild 0.28.2 and isolated parse5/entities modules (IIFE/browser/minify/legalComments=eof) to `candidate/worker-bundle.js`; serialize that bundle as `window.EDB_TASK22_WORKER_SOURCE = JSON.stringify(bundle)` in `candidate/worker-source.js`. Run `node --test --test-reporter=tap candidate/resource-cases.mjs candidate/isolation-cases.mjs`. The test import of the browser harness was changed from its original absolute scratch path to the equivalent sibling relative path solely for portability. The archived engine import preserves the original candidate directory structure.

The maintained production regression is `tests/tools/markdown-converter-previewer/`; it executes the checked-in local bundle and real isolated preview with network positive controls, without the prototype raw-HTML operation. Limits are bounded tested behavior, not a hard browser heap guarantee or comprehensive security certification.

Follow-up: the 31-case rendering-budget gate is archived in `security-gate-hardened.txt`. For that run, replace the scratch engine with `hardened-engine.mjs`, rebuild the same Worker and run `hardened-resource-cases.mjs` with the unchanged browser cases. The earlier 30-case archive remains intact.
