## Acceptance policies before implementation

* UUID: manual Generate action, default batch 1 and lowercase. Batch 1–1,000 (at most 16,000 entropy bytes / 36,999 output characters); optional uppercase display. Decimal whole-count input only, at most 4 characters before trimming. Require isSecureContext and crypto.getRandomValues; fail clearly if absent/throwing, never substitute another random source. Set version-4 and RFC variant bits on fresh browser random bytes. Settings edits invalidate old output/actions; no random generation on typing or page load. Clear restores count 1/lowercase with empty output. Pure DOM-free adapter deterministically validates quantity/byte arrays and formats supplied entropy; exact JSON/Node tests test formatting, not actual random acquisition. Real browser tests separately execute production Web Crypto, secure-context/unavailable/throwing paths, bit/format/batch/uniqueness checks and deterministic entropy stubs. No claim of global uniqueness, secrets generation or cryptographic certification.
* Timestamp: default explicitly selected epoch seconds; milliseconds and strict ISO input modes. 64 UTF-16 units maximum. Seconds allow signed decimal integers or 1–3 fractional digits; milliseconds are signed integers. No unit inference, exponent or grouping. Parse epoch decimal components with BigInt before exact conversion to integer milliseconds; Date range ±8,640,000,000,000,000 ms. Strict ISO YYYY or signed-six-digit year, full T time with seconds, optional 1–3 millisecond digits and mandatory Z or ±HH:mm; reject calendar rollover, leap seconds, 24:00 and negative-zero expanded year. UTC ISO and exact seconds/milliseconds form the copied/downloaded canonical UTC report. Device-local display is separately labeled with IANA zone and native Intl Gregorian era/time/offset; explicitly excluded from the UTC export. Test controlled browser UTC, New York DST and Kathmandu offsets. Local display depends on host timezone/Intl data; UTC conversion is deterministic. No date-only, ambiguous zone-free or sub-millisecond input; no precision-losing epoch multiplication.
* Calculator numeric model: two separately labeled text fields, each at most 64 UTF-16 units; complete ASCII decimals with optional sign/exponent and trimmed surrounding whitespace, no grouping/currency/percent symbols/hex/NaN/Infinity. Finite magnitudes ≤1e12, nonzero magnitudes ≥1e-12. Empty/invalid/out-of-range fields fail with named messages; zero is valid where formula permits. Reject nonfinite or result magnitude >1e15. JavaScript IEEE-754 arithmetic; display rounding 0/2/4/6 decimals, default 2; normalize displayed negative zero and disclose rounding/approximation. Output is bounded small text (<1,000 units), never a financial/accounting/currency-precision claim.
* Percentage Calculator: default p% of value = (p/100) × value; explicit second mode part ÷ whole × 100%, whole=0 error. Signed values/percentages allowed under numeric limits. Dynamic labels and displayed formula match mode; rounded result and formula report, valid original input preserved.
* Percentage Change: (new − starting) / abs(starting) × 100%; zero starting value always error, including 0→0. Negative bases supported with absolute denominator so increasing signed value is Increase and decreasing is Decrease; no-change labeled explicitly. Show difference, percentage and exact policy/formula; direction uses unrounded values while display may round a tiny change to 0.
* Discount: nonnegative original price; percentage inclusive 0–100. Savings = price × percentage / 100; final = price − savings. Original, savings and final independently rounded in report; displayed sums can differ from independent rounding. No tax, fees, currency symbols/conversion or cash-rounding assumptions.

All five: standalone vanilla HTML/JS, existing Tailwind Play CDN and expanded fallback CSS; no package/build/backend/API additions. Relevant controls only, native labels/focus/status/errors, top-left explicit ../index.html link, responsive 320/375/768/1440 layouts. Text results rendered with value/textContent, no input execution/injection/transport/logging/storage. Numeric small-field limits replace the text-specific 100,000-unit convention because these are count/date/calculator data models. Immediate invalidation of obsolete results/counts/copy/export, live deterministic preview with 120 ms debounce, deferred composition, manual UUID generation, Clear/default/focus reset, revision-guarded clipboard completion and truthful manual fallback. Fixed-name UTF-8 .txt export and object URL cleanup on success/failure. Owner homepage analytics and ordinary CDN delivery are preserved and distinguished from utility input processing.
