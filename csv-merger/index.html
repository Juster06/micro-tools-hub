    Rules, limits & privacy

    Choose 2–8 UTF-8 comma-delimited CSV files, at most 1 MiB each and 4 MiB total, and at most 500,000 decoded UTF-16 units per file. The first file supplies the exact ordered, case- and whitespace-sensitive header. Empty or whitespace-only and duplicate headers, differing header order or names, malformed quotes and records with a different number of cells are rejected. Quoted commas, escaped quotes and multiline fields are supported; line endings normalize to LF inside fields and output uses CRLF. Per file: 2,000 records, 100 columns, 20,000 cells and 10,000 units per field. Combined: 5,000 data records, 40,000 output cells, 2,000,000 output UTF-16 units and 4 MiB UTF-8. Preview contains at most 20 data records; download contains the complete bounded result. Export prefixes an apostrophe to cells beginning with tab, newline or whitespace/control characters before =, +, - or @ to reduce spreadsheet formula injection; affected values intentionally change. Check the output before use. Files stay in this browser.

    Hosting and the existing styling CDN are separate network requests. User input is not uploaded by this tool.
