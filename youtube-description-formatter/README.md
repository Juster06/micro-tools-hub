# YouTube Description Formatter

Canonical route: `youtube-description-formatter/index.html`.

Title is required and at most 200 UTF-16 units. Introduction, description sections, links, timestamps and hashtags are plain text, each up to 5,000 units and 16,000 total. Separate multiple description sections using a line containing three hyphens. Reorder the five categories using the buttons. Links are not validated or opened; output is not published.

Processing stays in the browser; hosting and the existing Tailwind styling CDN are separate network requests. Publication is pending separately authorized integration and live verification.
