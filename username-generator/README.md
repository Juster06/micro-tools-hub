# Username Generator

Canonical route: `username-generator/index.html`.

Up to 500 UTF-16 input units and 20 words, each at most 40 units. Words contain Unicode letters and digits. Choose case, optional separator, length 1–32 and up to 20 unique suggestions. Length is measured in Unicode code points. No account availability is checked; suggestions are not secure passwords.

Processing stays in the browser; hosting and the existing Tailwind styling CDN are separate network requests. Publication is pending separately authorized integration and live verification.
