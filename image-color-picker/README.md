# Image Color Picker

Static PNG only, up to 5 MiB; dimensions 1–4096 and at most 8 million pixels. Choose a pixel by pointer, keyboard arrows on the preview, or zero-based X/Y coordinates. HEX and RGB describe Canvas-decoded channel values; alpha is shown as 0–255. Fully transparent pixel RGB may be lost during browser decoding. No image upload or metadata-removal claim.

Input stays local; hosting and the existing styling CDN are separate requests. Publication is pending.
