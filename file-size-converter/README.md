# File Size Converter

Canonical route: `file-size-converter/index.html`.

SI uses powers of 1000; IEC uses powers of 1024. B means bytes, not bits. Plain nonnegative decimals only, at most 60 UTF-16 units and 30 fractional digits. Results use exact integer rational arithmetic, rounded half up to 12 decimal places; ≈ marks rounding. A positive result smaller than 0.000000000001 is shown as less than that threshold. No file upload or external API.

Processing is local; hosting and the existing Tailwind CDN may receive page requests. Publication remains pending until independently verified after separately authorized integration.
